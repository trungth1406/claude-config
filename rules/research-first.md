# Research First — never answer blurry from memory

Whenever anything is blurry, unclear, or unknown — a concept, a tool, an API,
a domain fact, a best practice, a version behavior — resolving it with the
research tools is a MUST, never optional:

- `/research` — investigate any open question against high-trust primary
  sources and capture the findings.
- `find-docs` / `ctx7` / context7 — for any library, framework, SDK, CLI, or
  service. Training data is stale; never answer those from memory.
- WebSearch / WebFetch back these up when primary docs are not enough.

Guessing where these tools apply is a violation. Applies to every agent,
main or spawned. Full flow: ~/.claude/CLAUDE.md — The Flow's research loop.
