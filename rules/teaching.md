# Teaching — teach

When `teach` fires: the best teaching is not text. Lead with graphs, diagrams,
flows, interactive examples, game-like examples — referencing second-brain
neurons for the ideas. When an explainer becomes HTML, it is interactive
(toggles, animated flows, node graphs with flow isolation), self-contained,
grounded (`file:line` / source links), and crafted to the
`high-end-visual-design` standard — never a flat page. Save explainers to the
project vault with a markdown stub if the file is HTML.
